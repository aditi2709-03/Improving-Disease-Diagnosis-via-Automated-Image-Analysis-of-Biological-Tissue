Microgels are nanoscopic, biologically relevant par cles, and the ability to detect them and count them 
precisely, is essen al to a variety of biomedical applica ons, par cularly in microfluidic diagnos cs. This thesis 
presents a lightweight, interpretable, and reproducible approach which can be used to detect and count these 
microgels in video data using a custom-trained convolu onal neural network (CNN). The project was based on 
such three microscopic videos of microgels flowing in a microfluidic channel where one video was annotated 
manually while other two represented independent test datasets. A modular pipeline was developed involving 
frame extrac on, data cleaning, bounding box annota on using Roboflow and CNN-based binary classifica on. 
The model produced a precision and F1 score of more than 95 percent. These findings prove that task-specific 
CNN, with careful preprocessing and mathema cal reasoning, can accommodate biomedical image analysis 
automa on, even in the cases with a limited amount of data and compu ng resources. The project sets a fine 
premise of the subsequent work, and with that, it opens the gates to other such tasks like temporal tracking 
and morphological measurement.
